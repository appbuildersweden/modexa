About the app

A small, focused desktop app

Modexa is a native shell built with Tauri 2 around a hand-written interface — no browser runtime in between, no account required to start, and nothing hidden in the background.

What it is

A workspace for AI agents: conversations, projects, reusable skills, MCP servers and model selection. The interface is plain HTML, CSS and JavaScript running inside the Tauri window.

Requirements

  • Windows 10 or newer (WebView2)
  • macOS 11 or newer, Linux with WebKitGTK
  • No runtime or Node.js install needed

Where data lives

Settings, themes and MCP servers are stored locally. Signing in with a cloud account syncs chats, projects, skills and daily usage to Supabase, protected per user.

Version & updates

Latest build · installer size. Updates are signed and delivered through GitHub Releases; the app checks on start and from Settings → Updates.

What do the model multipliers mean?

Every account has 21 hours of daily model time. A model marked 10× spends ten minutes of that time for each real minute it runs — a free model spends nothing. The meter in the picker shows what is left, live.

Do I need a server for Modexa?

No. The app runs on your machine and everything local works offline. A Supabase project is only needed if you want your chats and projects synced between devices.

How are MCP servers approved?

Paste the mcpServers block from the server's instructions, review the entry and approve it. Nothing runs until you have approved it, and you can revisit the choice from Settings → MCP at any time.

Which platforms are supported?

Windows installers are published today. macOS and Linux are built by the same GitHub Action and appear on the releases page as soon as a release runs on those runners.
